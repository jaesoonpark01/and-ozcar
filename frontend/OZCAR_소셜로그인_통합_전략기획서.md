# 오즈카(Ozcar) 차세대 소셜 로그인 및 대시보드 통합 전략 가이드

최근 플랫폼 비즈니스의 인증 트렌드는 단순한 소셜 로그인을 넘어, **웹2의 편리함(카카오/구글 로그인) 뒤에 웹3의 보안성과 자산 통합(하이브리드 임베디드 지갑)을 숨기는 Account Abstraction(ERC-4337)** 기술로 진화했습니다. 

단순히 사용자를 가입시키는 것에 그치지 않고, 로그인 즉시 **$OZ 토큰(oz-Point)을 받을 수 있는 데이터 지갑(Mining Wallet)을 자동으로 개설해주는 '무감각(Zero-Touch) 온보딩'** 전략을 오즈카 플랫폼에 적용하는 기획안입니다.

---

## 1. 2026 Authentication 핵심 트렌드: "Web3 Hybrid Auth (AA)"

일반 차주와 정비 마스터들에게 복잡한 블록체인 지갑(MetaMask 등)을 설치하라는 것은 플랫폼의 사형선고와 같습니다. 

* **최신 트렌드 (Account Abstraction)**: 사용자는 평소처럼 **'카카오로 1초 만에 시작하기'** 버튼을 누릅니다. 그러면 백엔드에서 소셜 Oauth 검증이 완료됨과 동시에 **사용자 전용 데이터 스마트 컨트랙트 지갑이 보이지 않는 곳(Under the hood)에 자동 생성(Embedded Wallet)** 됩니다.
* **가스비 대납 (Paymaster)**: 차주가 주행 데이터를 제공하고 마스터가 정비 이력을 블록체인(차량 NFT)에 기록할 때 발생하는 수수료(가스비)는 오즈카 플랫폼이 대납(Sponsor)하여, 사용자들은 코인 지식이 전혀 없어도 생태계를 누릴 수 있습니다.

> [!TIP] 
> 오즈카는 이 구조를 통해 "일반 차주도 카카오 로그인만 하면, 내 차의 주행 데이터와 정비 이력이 자산화되는 나만의 $OZ 지갑을 1초 만에 갖게 되는 마법"을 투자자 및 심사위원에게 강력하게 어필할 수 있습니다.

## 2. 하이브리드 로그인 플로우 (User Journey)

로그인 버튼을 눌렀을 때부터 대시보드로 진입하기까지의 "최상의 전환율(CVR)"을 위한 플로우입니다.

### 🛑 1단계: Oauth 소셜 로그인 분기
- **일반 차주 (소비자)**: 한국 시장 점유율이 압도적인 `카카오`, `네이버` 로그인을 최상단에 배치합니다.
- **정비 마스터 & B2B/B2G 기업**: 글로벌 확장성 및 기업용 SSO, 지자체 통합을 고려해 `구글` 및 `이메일(Magic Link)` 로그인을 배치합니다.

### 🛑 2단계: Auth Provider ➔ Embedded Wallet 발급
- Next.js의 NextAuth(Auth.js) 또는 Supabase Auth를 통해 세션을 발급받습니다.
- 소셜 계정의 고유 ID(Provider ID)를 시드(Seed)로 사용하여 개별 사용자의 **$OZ 마이닝 지갑을 즉석에서 매핑**합니다. (이때 사용자는 짧은 로딩 화면 하나만 보게 됩니다.)

### 🛑 3단계: Role-Based Routing (역할 기반 대시보드 강제 이동)
로그인이 완료되고 지갑이 생성되면, 사용자의 `Role(권한)`에 따라 대시보드가 자동으로 분리되어야 합니다.

* `Role: CAR_OWNER (일반 차주)` ➔ `/my-garage` (자산 방어 시뮬레이터 및 토큰 채굴 현황)
* `Role: PRO_MASTER (정비 마스터)` ➔ `/master-license` 또는 `/maintenance/inspection` (20-Min Cut 고속 점검 패널)
* `Role: CORPORATE (데이터 구매 기업)` ➔ `/marketplace` (지자체 및 지도사의 Data-Market API 구독 관제실)
* `Role: ADMIN (최고 관리자)` ➔ `/admin` (오즈카 총괄 관리 및 토큰 수익/소각 대시보드)

## 3. 프론트엔드 (Next.js) 구현 아키텍처

사용자 경험의 단절을 막기 위한 코드 설계 가이드입니다.

### 🛠 Auth Wrapper 구축 (가장 추천하는 스택: Supabase Auth + Privy.io)
최근 스타트업씬에서 가장 폭발적인 인기를 끌고 있는 **Privy.io(또는 Web3Auth)** 와 **Supabase**의 조합을 권장합니다.

1. **상태 관리 주입**: Navbar 컴포넌트를 `<AuthProvider>`로 감싸 세션(Session) 값을 전역에서 감시합니다.
2. **모달 팝업 호출**: `<UserCircle />` 등 Navbar의 로그인 버튼에 `onClick={() => openLoginModal()}`을 연결하여, 화면 중앙에 미려한 [카카오/네이버/구글 시작하기] 글래스모피즘 모달이 뜨게 합니다.
3. **미들웨어(Middleware.ts) 방벽**: 사용자가 로그인 없이 마스터 전용 공간이나 기업용 Data-Market URL을 강제로 치고 들어올 경우, Next.js의 미들웨어가 이를 낚아채서 안전하게 로그인 모달 화면으로 반환시킵니다.

## 4. [투자자 및 심사위원] 핵심 설득 논리 (Pitching 포인트)

이 기술적 결정을 IR 피칭이나 문서에서 다음과 같이 포장하여야 합니다.

> "심사위원님, 모빌리티 데이터를 블록체인과 결합해 자산화하는 Web3 인프라는 필연적으로 진입 장벽이 높습니다."
>
> "저희 오즈카(Ozcar)는 **Zero-Knowledge(영지식) 임베디드 지갑 아키텍처**를 채택했습니다. 일반 차주가 평소처럼 **카카오톡 로그인 버튼 한 번만 누르면, 그 즉시 내 차의 가치를 방어하고 데이터를 팔아 수익을 내는 $OZ 토큰 지갑이 보이지 않는 곳에서 자동 생성**됩니다."
> 
> "플랫폼이 가스비(수수료)를 대납하고, 차주는 그저 기존 정비 앱처럼 차량을 관리하며 혜택(정비 바우처, 세차권)만 빼가면 됩니다. 데이터 수익화의 모든 허들을 카카오 로그인 뒤로 완벽히 숨긴 것, 이것이 오즈카가 가진 모빌리티 혁신의 절대적인 무기입니다."
